# tally

A small command-line tool that counts words and lines in a text file. It uses only the Python
standard library and runs on Python 3.9 or later.

This repository is the sample the Agent Blueprint hosted demo works on: visitors ask the agent for a
small change here and get a pull request back.

## Install

```bash
pip install -e .
```

## Tests

```bash
python3 -m unittest
```

## Contributing

Pull requests are welcome. To propose a change:

1. Fork the repository and create a branch from `main`.
2. Make your change, adding or updating tests if it touches code.
3. Run `python3 -m unittest` from the repository root and make sure it passes.
4. Open a pull request describing what the change does and why.

Bug reports and ideas for improvements go to the
[issue tracker](https://github.com/Ninety2UA/agent-blueprint-sample/issues).
